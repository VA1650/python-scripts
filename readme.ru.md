# 🐍 Python-скрипты

## Легковесный системный монитор (Flask + Docker)

Минималистичный Python-микросервис, предназначенный для предоставления метрик здоровья системы в реальном времени через REST API.

## ✨ Ключевые возможности
* **Инъекция окружения:** Динамическое получение конфигурации хоста через переменные окружения.
* **Мониторинг ресурсов:** Отслеживание нагрузки на CPU и RAM с использованием библиотеки `psutil`.
* **Docker-архитектура:** Полная контейнеризация для быстрого развертывания в любой среде.
* **Production-Ready:** Реализован запуск от имени пользователя без прав root и безопасная привязка к хосту.

## 🛠 Технологический стек
* Python 3.11 / Flask
* Docker
* psutil

## Генератор QR-кодов

Инструмент для быстрого создания QR-кодов с возможностью настройки уровня коррекции ошибок и цветовой схемы.

## ✨ Ключевые возможности
* **Генерация на лету:** Мгновенное создание QR-изображений из переданных строк или URL.
* **Кастомизация:** Поддержка изменения размера модулей, отступов (border) и цветового оформления.
* **Интеграция:** Удобный CLI-интерфейс для пакетной обработки данных.

## 🛠 Технологический стек
* Python 3.x
* qrcode (библиотека для генерации)
* Pillow (для обработки изображений)
